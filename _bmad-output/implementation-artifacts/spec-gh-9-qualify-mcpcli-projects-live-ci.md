## Intent

McpCli's required live lane fails `projects.list` with HTTP 503 because its committed Gateway catalog lacks Projects. Issue #9 makes the central checkout conditional on a qualified package-mode Release fixture. The user approved taking on McpCli Story 5.21 upstream with envelope paging.

## Boundaries & Constraints

Reuse the shared CLI and MCP execution paths and the real Gateway, Projects server and tenant-access worker handlers. Use synthetic identities with narrow grants and seed through supported owner commands and callbacks in disposable infrastructure. Preserve the existing approval-bound vector, fail-closed authority checks, and compatibility for existing Projects list callers. Keep central CI ownership in CiCd. Bind acceptance to exact source and package identities and completed live runs.
